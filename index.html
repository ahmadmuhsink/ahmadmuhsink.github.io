All aboard: the journey so far

Six stops between Bandung and Zaandam. Open a ticket to see what I did there.

  1. 2022 – now Zaandam Albert Heijn

    Senior Software Engineer, Mobile Apps. I work on Checkout, Digital Wallet and Loyalty in the Albert Heijn app, with accessibility in every feature for the European Accessibility Act.

    • Built My Wallet and the coupons on a server-driven UI, with each feature as a block.
    • Turned coupons into a catalog with filters, sorting and themes from the CMS.
    • Added iDEAL, debit card tokenization, digital koopzegels and gift cards to checkout.
    • Built the Prijzenrad summer campaign and the World Cup 2026 opt-in flow.
    • Split the Loyalty Wallet code into clear layers, with lint rules that guard the borders.
  2. 2021 – 2022 Amsterdam Backbase

    Senior Software Engineer, Mobile Apps, in Retail Banking.

    • Designed a unified omnipayment flow: many payment methods, one experience.
    • Delivered core banking features with the same behavior on every mobile channel.
  3. 2019 – 2020 Utrecht Blendle

    Senior Software Engineer, Mobile Apps, for a premium news app that moved from pay per article to a subscription.

    • Moved the old code to Kotlin and Clean Architecture.
    • Rebuilt the full app UI for the new brand.
    • Built a server-driven home page, so the backend could run A/B tests on the layout.
    • Added subscription payments with Stripe.
  4. 2017 – 2019 Jakarta GoTo · GoFood

    Senior Software Engineer, Mobile Apps, for GoFood: more than 2.5 million daily customers and 3 million orders a day.

    • Built the server-driven UI for the new GoFood home screen.
    • Ran remote configuration and A/B tests at scale.
    • Built order placement, live driver tracking and menu discovery.
    • Kept the app fast and stable at lunch-rush traffic.
  5. 2014 – 2017 Rotterdam NiceDay

    From Software Engineer to Senior, on a platform for mental health care.

    • Led the patient app and the therapist app: log moods, track progress, talk securely.
    • Collected sensor data in the background without draining the battery.
  6. 2012 – 2014 Bandung Torche Indonesia

    Software Engineer, Web Apps. My first stop: PHP web apps for public sector clients, and the basics of databases and deployment.

    In the same years, I finished a Bachelor's degree in Information Technology at Telkom University (2014).
